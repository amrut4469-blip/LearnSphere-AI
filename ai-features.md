# 🧠 AI Features

| Capability | Description |
|---|---|
| **Document understanding** | Reads the uploaded notes, syllabus or paper and uses it as the source of truth. |
| **Context-aware generation** | Uses exam name and subject/chapter to shape output. |
| **Doubt solving** | AI Assistant and AI Tutor explain step by step. |
| **Question scanning** | Reads printed or handwritten questions from camera or gallery images. |
| **Voice tutoring** | Conversational learning with the Voice AI Tutor. |
| **Video-style notes** | Condenses content into short, revisable notes. |
| **Practice generation** | Creates questions for the Practice Arena from the uploaded material. |
| **Smart revision** | Helps revise key points before exams. |

## Guardrails
- Output is based on the student's document.
- No fabricated progress numbers.
- AI is a study aid; verify critical facts with textbooks or teachers.
